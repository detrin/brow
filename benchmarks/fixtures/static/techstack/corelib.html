CoreLib

Version: 2.1.0 License: MIT Type: Utility library

Foundational utilities for the Nexus ecosystem. Provides string manipulation helpers, date formatting, collection utilities (map, filter, group-by), and deep equality checks used throughout the framework.

Key Features

  • String interpolation and templating
  • Date parsing and formatting (ISO 8601, relative)
  • Immutable collection helpers
  • Type-safe deep merge and clone
