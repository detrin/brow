Logger

Version: 2.0.1 License: MIT Type: Observability

Structured logging library with configurable log levels, pluggable formatters (JSON, pretty-print, logfmt), and transport plugins for stdout, files, and remote collectors (OpenTelemetry, Datadog).

Key Features

  • Log levels: TRACE, DEBUG, INFO, WARN, ERROR, FATAL
  • Structured key-value context attached to log entries
  • Async transport queue with back-pressure
  • Child loggers with inherited context
