AuthKit

Version: 3.0.0 License: MIT Type: Security

Authentication and authorization toolkit for the Nexus ecosystem. Supports OAuth2 flows, JWT issuance and validation, session management with sliding expiry, and role-based access control (RBAC).

Key Features

  • OAuth2 / OpenID Connect provider and client
  • JWT signing (RS256, ES256) and verification
  • Session store with Redis and in-memory adapters
  • Declarative RBAC with permission inheritance
